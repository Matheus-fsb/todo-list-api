# Documentação da Todo List API

Este site de documentação foi criado com [Docusaurus](https://docusaurus.io/).

## Instalação

```bash
npm install
```

## Desenvolvimento Local

```bash
npm run start
```

Esse comando inicia o servidor local da documentação.

## Compilação

```bash
npm run build
```

Esse comando gera os arquivos estáticos no diretório `build`.
